별별마켓 - 중고 거래 웹 서비스 개발
==================

작업 기간
------------

2024.01 ~ 2024. 04 (4개월)

인력 구성
------------

BE 1명, FE 1명, ML 1명

프로젝트 목적
----------------------
Django와 JavaScript 기반의 중고 거래 플랫폼 개발

개인 프로젝트로 웹 서비스 전반을 구현하며 백엔드, 프론트엔드, 머신러닝 경험 축적

사용자 친화적인 UI/UX 설계 및 데이터 동기화 경험을 쌓기 위해 진행


주요 업무 및 상세 역할
---------------------

* 프론트엔드 및 백엔드 개발
  * Django 기반 RESTful API 구축 및 데이터 동기화 구현

  * JavaScript Fetch API를 활용한 비동기 처리 및 UI 연동

  * HTML/CSS 및 JavaScript로 상품 등록, 검색, 채팅 기능 개발

* 머신러닝 모델 개발

  * 사용자 위치 데이터를 활용하여 추천 시스템 구현

  * Google Geocode API를 활용한 위치 데이터 처리 및 시각화

  * Python 기반 데이터 전처리 및 모델 학습

* 관리자 페이지 개발

  * 상품/회원 관리 기능 및 데이터 시각화 대시보드 제작

  * 통계 그래프(Chart.js)를 활용하여 사용자 활동 분석

사용 언어 및 개발 환경
-----------------------

* Python (Django), JavaScript, HTML/CSS

* Google Maps API, Chart.js, JSON 데이터 관리

* GitHub를 활용한 협업 및 버전 관리

느낀 점
-------------------

* 비동기 처리 및 데이터 동기화의 중요성을 학습

* 관리자 페이지 및 데이터 분석 기능을 추가하면서 사용자 경험 개선의 중요성을 체감

* 머신러닝 모델과 웹 서비스의 연동 과정에서 데이터 전처리의 난이도를 경험

* 팀원과의 협업을 통해 Git 관리 및 코드 리뷰의 중요성을 배움
